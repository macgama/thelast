# Prompts des 100 personnages

Deux prompts par personnage, à copier tel quel dans un outil d'image ou de 3D pour obtenir sa planche de référence (face, profil, dos) :

- **Cinématique** : 3D stylisée haut de gamme, pour les petites cinématiques.
- **Low poly** : le style du jeu.

Généré depuis `data/looks.json` par `npm run looks`.
